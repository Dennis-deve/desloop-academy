## Operator controls that exist

- `.railway/railway.ts` describes app+private DB, Amsterdam, Node 22, pre-deploy `engine:migrate`, health `/api/health`, adult-only flags and closed `APP_ORIGIN`. Always run `railway config plan` and review additions/deletions before `apply`; do **not** add a public domain/TCP proxy as a shortcut.
- Pre-deploy aborts on migration failure; app startup verifies content versions and safeguarding hold. `/api/health` checks DB connectivity when adult engine enabled. Railway healthcheck readiness is **not** continuous monitoring.
- Restricted operator CLI can issue private adult invitations, assign reviewers, inspect pending submissions and disable adult accounts; actions are audited in the application DB. None of this provides recovery/MFA or tamper-proof external audit retention.
- Rollback adult exposure by switching `PILOT_ENABLED=false` and `ENGINE_V2_ENABLED=false` via reviewed IaC plan/apply. AI-01's new IaC flags are explicitly false; if an **independently approved private synthetic** service later enables them, disable `AI_GATEWAY_ENABLED`/`AI_ADMIN_UI_ENABLED` and the model route, then revoke any affected provider key through its dashboard. A disabled gateway closes API/deep links but **does not erase records or reverse provider charges**. Do not run local test reset, `TRUNCATE` or `DROP` against Railway.
- New AI-01 operations are intentionally separate: reviewed manual `ai-migrate` after backup, explicit membership grant for an existing active adult reviewer, owner-approved charge for a fixed synthetic real-model verification, then disable live-test flag. See [runbook](AI_GATEWAY_RUNBOOK.md). Local usage/cost is a conservative reservation, **not** an invoice or upstream spending guarantee. Alert owner on repeated 429, invalid output, upstream policy change, 80% cap and missing/expired verified model. Physical deletion for 30-day logical draft expiry is still **unimplemented**; do not assume expired rows have been erased, and do not schedule destructive purges without a reviewed retention policy/backup/restore plan.
