# AI-01 provider due diligence — 22 October 2026

**Scope:** publicly accessible official documentation inspected for **Gemini API, GroqCloud, OpenRouter, Cloudflare Workers AI, NVIDIA NIM and local Ollama**. No owner account, API key, project-specific quota, contract, DPA, model entitlement or real API response was available. These are **candidate adapters, not operational or production-ready providers**. Recheck the exact account and selected model on the day of any live test; obtain written legal/privacy/security/spend approval separately. The [implementation runbook](AI_GATEWAY_RUNBOOK.md) and [feature register](FEATURE_REGISTER.md) control rollout.

## NVIDIA model selection from the official catalogue (not account-verified)

- **Text candidate for synthetic reviewer tasks:** exact hosted model ID **`nvidia/nemotron-3.5-lightning-30b-a3b`**, from [1](https://build.nvidia.com/nvidia/nemotron-3.5-lightning-30b-a3b). Official page documents text-in/text-out, chat/instruction/reasoning/coding uses, context **up to 1M tokens**, and a hosted request example with `max_tokens=16384` and optional model-specific reasoning parameters. The generic adapter intentionally sends plain text non-streaming chat **without tools or thinking extras**; it validates the normal `content` and `finish_reason='stop'`, rejects returned reasoning traces/tools/truncation, and caps requests far below the advertised context. The open model's commercial licence is **not** a licence for production use of the hosted developer endpoint. **No per-account entitlement, free quota, output headroom or real response verified.** [1](https://build.nvidia.com/nvidia/nemotron-3.5-lightning-30b-a3b) [12](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-5-lightning-30b-a3b) [1](https://docs.api.nvidia.com/nim/docs/product)
- **Future multimodal candidate, NOT assigned or implemented:** exact hosted model ID **`nvidia/nemotron-3.5-super-vl-120b-a12b`**. Official documentation states text/images/video **input**, text **output**, up to 1M shared context, reasoning/tool-use capability dependent on endpoint; hosted snippet shows image input shape and model-specific settings. This text-only gateway accepts no files, image/video or tool calls, so multimodal capability is **not operational**. Require consent, image redaction/licence checks, child-data review, per-model input/size/output verification, safe renderer and real integration tests in a separate feature before offering it. [1](https://build.nvidia.com/nvidia/nemotron-3.5-super-vl-120b-a12b) [13](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3_5-super-vl-120b-a12b)
- **Teaching, reasoning, code, questions:** catalogue descriptions make Lightning a **candidate** for these text-only tasks, not an educational-quality certification. An authorised reviewer must verify exact hosted model capability, compatible context/output settings, quota and response format with a real development-only request, then perform safeguarding, accessibility and curriculum quality evaluation before choosing a task route. **Tool calls remain disabled even if the model supports them.**

**Account setup evidence still required for EACH selected model:** console screenshot or restricted ticket with account owner, exact model ID/version, capability/price page checked date, account RPM/TPM/day cap and free-credit expiry, model licence, applicable end-user age/commercial terms, input/output retention/training/region, DPA/controller approval, cap/spend alert, credential rotation owner, synthetic real-call ID/time (no key or prompt in public repo), failure case and reviewer.
