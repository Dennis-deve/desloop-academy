# REA Phase 1 — Scratch GUI and GDevelop source analysis

**31 October 2026 · Research-only deliverable.** No editor was embedded, no Desloop application code or deployment was changed, no child accounts were enabled, and no production or third-party project/build API was called. This is a **focused source study**, not a complete audit of either repository. The existing [read-only public guide](https://desloop-readonly-guide.onrender.com) remains the sole approved public surface. Later studio choices require explicit licensing, architecture, safety, cost and accessibility decisions.

## Executive finding

- **Scratch GUI** offers a genuine blocks–VM–stage design relevant to the future 7–11 experience. Its GUI and VM identify as **AGPL-3.0-only**; the GUI expects React 16 peers and Scratch-specific storage/identity hosts. Do **not** drop it into the current Desloop bundle or treat Scratch cookies/tokens as Desloop authentication. [GUI package](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/package.json#L1-L6), [React peers](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/package.json#L98-L103), [VM package](https://github.com/scratchfoundation/scratch-vm/blob/b3266a0cfe5122f20b72ccd738a3dd4dff4fc5a5/package.json#L1-L7).
- **GDevelop's new IDE** is MIT-licensed, but its running browser editor depends on compiled `libGD.js`, GDJS, browser preview/service-worker machinery and its own cloud/build APIs. Its desktop/web editor is not a lightweight drop-in React panel or a Supabase save component. Original Flow-annotated files failed REA's direct JavaScript parse; an explicitly labelled, source-mapped Flow-stripped copy was then successfully parsed. [IDE README](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/README.md#L1-L27), [IDE MIT notice](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/LICENSE.md#L4-L16).
- **Recommendation, not an authorisation:** retain the current React/Vite/Fastify/PostgreSQL system and isolated public guide while evaluating a separately isolated **real** adult/internal studio and a Desloop-owned, server-authoritative project adapter. Treat Next.js 14 + Supabase + Prisma as a proposed migration requiring a separate owner decision and tested data/security migration, not as a change already made. Do not ship a fake editor, autosave indicator, build, classroom or arcade.

## Source findings with consequences for Desloop

### Scratch GUI: usable design reference; integration/legal gate

1. Its [GUI HOC stack](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/containers/gui.jsx#L198-L214) coordinates localization, project fetching/saving, VM listeners/manager and storage. The [editor UI](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/components/gui/gui.jsx#L254-L366) contains code/costume/sound tabs and stage. [Blocks inject a workspace and attach VM listeners](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/containers/blocks.jsx#L92-L107); workspace updates/teardown require explicit synchronization and disposal [here](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/containers/blocks.jsx#L260-L292). This is a real engine integration, not a static draggable UI.
2. The [VM manager](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/vm-manager-hoc.jsx#L30-L75) attaches audio, starts runtime and calls `vm.loadProject`. The sampled VM validates on [project load](https://github.com/scratchfoundation/scratch-vm/blob/b3266a0cfe5122f20b72ccd738a3dd4dff4fc5a5/src/virtual-machine.js#L303-L360) and can export an SB3 ZIP with `project.json` and assets [here](https://github.com/scratchfoundation/scratch-vm/blob/b3266a0cfe5122f20b72ccd738a3dd4dff4fc5a5/src/virtual-machine.js#L384-L407). A Desloop project format/asset migration and independently verified round-trip are needed; a screenshot or JSON field alone is not a saved playable project.
3. [Save](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/project-saver-hoc.jsx#L219-L255) snapshots VM JSON, uploads dirty assets, then sends project data and marks it unchanged on success. The default [autosave interval is 600 seconds](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/project-saver-hoc.jsx#L400-L405), gated on project-changed/saveable [state](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/project-saver-hoc.jsx#L134-L150). A 10-minute default is **not** evidence of Ghana 3G resilience or lossless offline work. Design a short, recoverable, versioned save contract instead of copying this policy.
4. [Fetcher defaults point to Scratch's own project/asset hosts](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/project-fetcher-hoc.jsx#L74-L89), [including default host settings](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/project-fetcher-hoc.jsx#L137-L140). [Storage uses a project token in a GET URL and credentialed web requests](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/storage.js#L35-L73); [project save uses cookie credentials](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/lib/save-project-to-server.js#L18-L61). A future Desloop adapter must use **Desloop's server-owned identity, ownership and storage**, with no browser secret or Scratch-token reuse.
5. [Stage creation attaches a renderer and video provider](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/src/containers/stage.jsx#L54-L77); the VM supports loading extensions [by ID/URL and worker](https://github.com/scratchfoundation/scratch-vm/blob/b3266a0cfe5122f20b72ccd738a3dd4dff4fc5a5/src/extension-support/extension-manager.js#L137-L163). Require an extension and device-permission allowlist, lifecycle/resource caps and verified child-safety approvals before exposing such capabilities.

### GDevelop: stronger permissive IDE licence; heavier product boundary

1. The IDE [README explicitly describes React, Pixi, Three, Electron and C++ compiled to JS](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/README.md#L1-L27). The sampled [storage-provider interface](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ProjectsStorage/ProjectStorageProviders.js#L108-L155) chooses provider operations, but its cloud writer is coupled to authenticated GDevelop services. [Serialization creates and checks a ZIP](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ProjectsStorage/CloudStorageProvider/CloudProjectWriter.js#L43-L98), then [requests a presigned URL, checks for conflict, commits and records a version](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ProjectsStorage/CloudStorageProvider/CloudProjectWriter.js#L199-L249). [A changed current version prompts before overwrite](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ProjectsStorage/CloudStorageProvider/CloudProjectWriter.js#L549-L588). Use the **pattern** of version/conflict/recovery, not a claim that its service is interchangeable with Supabase.
2. GDevelop [resource authorization uses Firebase user identity and a GDevelop API](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/Utils/GDevelopServices/Project.js#L230-L256); [version commit uploads a ZIP then calls a GDevelop backend](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/Utils/GDevelopServices/Project.js#L326-L380). Its [Android build call takes authenticated parameters, a key and `payWithCredits`](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/Utils/GDevelopServices/Build.js#L272-L309). Neither a free build service nor the proposed "$5 per active student" Render economics follows from this source. Obtain terms, pricing, rights and measured usage **before** any paid build/hosting decision.
3. Browser preview [exports via `gd.Exporter` to a generated path](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ExportAndShare/BrowserExporters/BrowserSWPreviewLauncher/index.js#L32-L76); [writes preview files to IndexedDB then opens frames/windows or hot-reloads](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ExportAndShare/BrowserExporters/BrowserSWPreviewLauncher/index.js#L287-L365). Its [preview URL is based on the page origin](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ExportAndShare/BrowserExporters/BrowserSWPreviewLauncher/BrowserSWPreviewIndexedDB.js#L46-L64), and the app [registers a service worker](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ServiceWorkerSetup.js#L18-L38). The [JavaScript event editor accepts inline code](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/EventsSheet/EventsTree/Renderers/JsCodeEvent.js#L294-L317). **Security inference:** do not host user-authored previews on the authenticated academy origin; separately assess origin/CSP/sandbox, worker scope, credential isolation, scripts, resource URLs and cross-tenant cache boundaries. A mere iframe does not establish isolation.
4. Its [cloud autosave is a user/project-keyed IndexedDB cache](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/Utils/ProjectCache.js#L5-L22) which [writes serialized project JSON](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/Utils/ProjectCache.js#L194-L212); [opening a cached project checks logged-in identity and cloud credentials](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ProjectsStorage/CloudStorageProvider/CloudProjectOpener.js#L50-L75). Cache ≠ authoritative save or cross-device availability. Shared-device logout, deletion, browser compatibility, quota, backup and version conflicts need Desloop tests. The writer's own [comment says background serialization is hardcoded off in MainFrame](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ProjectsStorage/CloudStorageProvider/CloudProjectWriter.js#L54-L65); low-RAM performance is **unknown**, not certified.
5. Its [HTML5 browser exporter runs a GDJS export, downloads resources and archives a game ZIP](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/ExportAndShare/BrowserExporters/BrowserHTML5Export.js#L75-L156). [Course task UI has a manually toggled checkbox](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/Course/TextBasedCourseChapterTaskItem.js#L44-L100); this sampled UI does **not** provide Desloop's required server-verified auto-checks or teacher permissions. [Event-list code acknowledges virtualized rendering](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/app/src/EventsSheet/EventsTree/index.js#L80-L85), not an observed low-end-device performance result.

## Licensing and integration gate

[Scratch GUI](https://github.com/scratchfoundation/scratch-gui/blob/dae2a97a5bb0cd8a7513fafd60f9e7488f2a89a4/LICENSE) and [Scratch VM](https://github.com/scratchfoundation/scratch-vm/blob/b3266a0cfe5122f20b72ccd738a3dd4dff4fc5a5/LICENSE) have AGPL-3.0-only package declarations. A qualified reviewer must determine source-offer, network-interaction, derivative/combination, attribution and dependency obligations **for the actual proposed integration**; hosting in a separate iframe is not a legal shortcut. GDevelop's [root licence note](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/LICENSE.md#L1-L4) calls Core, GDJS, new IDE and extensions MIT but reserves its name/logo; the [IDE MIT text](https://github.com/4ian/GDevelop/blob/85ab0e40e00fdc775e22e014fb885d2390705827/newIDE/LICENSE.md#L4-L16) requires notices. Audit the **specific** assets, libraries, build output and hosted-service terms separately. This is technical triage, **not legal advice or licence clearance**. No upstream code/assets were added to the Desloop runtime.

## Incremental integration proposal (decision pending)

1. **Preserve release boundaries and curriculum.** Keep the public 44-course, branded, original-image guide read-only; keep the adult/private engine and its Railway PostgreSQL data separate. Map proposed Game Dev, Web Dev, Programming, AI, Cybersecurity and Creative Tech tracks to the **one ordered versioned 44-course curriculum**, not six unapproved independent progress ledgers. Age bands 7–11/12–17/18+ are content-design targets; minor accounts and school access remain hard-off until qualified guardian/privacy/safety review.
2. **Choose a real studio candidate before shipping UI.** Privately build/inspect actual Scratch and GDevelop editor/runtime dependencies at pinned versions and an owned sample project; import → edit → preview → close/reopen → export must work. Compare a legally reviewed Scratch variant against a GDevelop browser deployment on a representative low-RAM Android device and Ghana-relevant 3G profile. Record cold/warm bytes, first-interaction time, memory, crashes, offline/reconnect behavior and keyboard/AT findings. A genuine editor that fails these gates is not disguised with decorative blocks or a fake preview. Web/Python/cyber studios need **separate** safe-execution designs; neither studied game editor proves those tracks exist.
3. **Define Desloop-owned project contracts before a save button.** Propose `project_id`, `owner_user_id`, optional future `tenant_id`, `lesson_version`, `studio_kind`, immutable `revision_id`, content digest, asset manifest, moderation/publish state and optimistic version. Implement server-side ownership/tenant/class checks; signed restricted object access, file validation and quotas; explicit pending/saved/conflict/error/retry/recovery states; idempotent writes and offline draft/merge policy only after shared-device privacy review. Do not trust local XP, client grades or a browser service key. Existing `pilot.*`/`learning.*` PostgreSQL migrations must be mapped and migration/rollback tested **before** contemplating Supabase/Prisma tables `users/tracks/lessons/projects/classes`.
4. **Builds and teaching require independent authority.** Use an isolated preview origin and reviewed CSP/worker scope; allowlisted execution, expiry and abuse controls. Only a real, measured, bounded build worker or approved provider may make a playable artifact; publishing/arcade/gallery stays private and moderated by default. Future teacher presence/comments/classes require verified staff identity, school tenancy, data minimization, audited access, moderation and cross-class tests. Project auto-checks must compare a versioned rubric against trusted artifact evidence server-side with human review where necessary; never equate a checkbox with credit. Cyber containers/terminals are **not** authorised by this game-studio study.
5. **Owner decisions before implementation:** (a) retain the existing React/Vite/Fastify/Railway PostgreSQL backbone with a separate editor origin **or** approve a planned Next.js/Supabase/Prisma migration; (b) choose a specific code/licence path after legal review; (c) approve realistic per-student performance/cost budgets and providers; (d) decide private adult tester/teacher scope. Neither decision enables minors, public studios, paid builds or an adult browser ingress by implication. Do not ask for secrets in chat.

**Acceptance evidence for a later feature ID:** actual edit/round-trip and durable revision records; denied owner/tenant/class cross-access; tampered grade/XP rejected; honest offline/save-conflict recovery; script/preview-origin and upload abuse tests; representative 320px/touch/keyboard/AT and low-RAM/3G benchmarks; legal/privacy/moderation/operations review. Until then, this is research, **not** `VERIFIED_COMPLETE` studio functionality.

**Not examined / not claimed:** entire repositories, all dependencies or licences, compiled GDevelop engine or shipped bundle, real Scratch/GDevelop account access, Supabase integration, active classroom/teacher flow, actual student testing, mobile/3G performance, provider/build pricing, manual WCAG 2.2 AA certification, or live Desloop studio release.
