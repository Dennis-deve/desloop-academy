# Phase 2 research-only browser evidence (31 October 2026)

This folder contains **seven single-run JSON observations**, four lab scripts and a file-hash [`manifest.json`](manifest.json). No Scratch or GDevelop executable, asset, project, credential or learner record is shipped in the Desloop product. Nothing here is a released feature, accessibility certification, legal clearance or a saved Desloop project. The prior static REA evidence is in [`../rea-phase1/`](../rea-phase1/).

| Results | What was actually run |
|---|---|
| [`scratch-standalone-baseline.json`](results/scratch-standalone-baseline.json), [`slow.json`](results/scratch-standalone-slow.json), [`heap128.json`](results/scratch-standalone-heap128.json) | Integrity-checked **current** `@scratch/scratch-gui@15.3.0` UMD `dist`, served by a one-shot HTTP server on `127.0.0.1` with gzip for the exact standalone JS and a small research mount script. `projectId:'0'` loads the built-in Stage + Sprite1; `canSave:false`; local browser outbound requests denied; UI green flag produced one real `PROJECT_START` VM event. The server closes after each run. No Desloop code import or public preview. |

A blank scene boot is **not** a complex playable-game benchmark. |

**Environment and budgets:** Debian 13 x86_64 lab, Playwright 1.64.1, Chromium headless shell 156.0.8078.4, 1280×800 viewport. `slow` uses CDP `Network.emulateNetworkConditions`: 150 ms latency, 100,000 bytes/s download (~0.8 Mbps), 50,000 bytes/s upload (~0.4 Mbps), and `Emulation.setCPUThrottlingRate` ×4. `heap128` passes Chromium `--js-flags=--max-old-space-size=128`, observed JS heap limit **139,000,000 bytes**; this does **not** cap DOM, GPU, shared pages, other processes or total physical RAM. Maximum duration: Scratch 55 s baseline/heap128 and 150 s slow; GDevelop 80 s baseline/heap128 and 180 s slow; each editor probe has a 60 MiB (GDevelop) or 80 MiB (Scratch) transfer cutoff. The preview script is an unthrottled, bounded one-shot (with per-action navigation waits). The JSONs include actual timings and incomplete-load warnings. No packet-loss emulation, mobile viewport, real Ghana ISP, physical low-RAM device or repeated statistical sample was tested.

**Reproduction (research workspace only, not a product build):**

1. Obtain the named package from npm in a **temporary, non-product directory**. Verify its raw tarball SHA-512 against the registry `dist.integrity` and its SHA-256/byte count against [`manifest.json`](manifest.json), then extract `package/dist` **without source maps**. The published npm distribution is AGPL-3.0-only with a separate trademark notice; do not add it to this application or deploy it without a legal/brand decision.
2. Install `playwright@1.64.1` and its compatible Chromium headless shell to a disposable lab directory; provision required Debian browser libraries. Set `PLAYWRIGHT_BROWSERS_PATH`, `PHASE2_PLAYWRIGHT` (path to its installed package) and `PHASE2_SCRATCH_DIST` (extracted `package/dist`). The scripts have the original lab paths as fallback for this workspace. `browser_memory.cjs` uses Linux `/proc/*/smaps_rollup` and the browser path to sum **proportional set size (PSS)** for the headless Chromium process family, when run alone. A single PSS snapshot is neither peak memory nor a Ghana phone measurement.
3. From this `scripts/` folder, run `node scratch_standalone_probe.cjs baseline|slow|heap128 OUT.json`, `node bench_editor.cjs https://editor.gdevelop.io/ baseline|slow|heap128 OUT.json gdevelop-empty`, or `node preview_gdevelop.cjs OUT.json`. Network tests must be **sequential**, not concurrent, to avoid bandwidth/CPU interference. Untrusted external site content can change and a hosted run may need a new, reviewed script rather than claiming exact reproduction.
4. Recompute SHA-256 for the stored scripts and JSON files and compare with the manifest. Do **not** replay any real user project or publish a vendor-labelled interface as Desloop.

**Interpretation traps:** CDP `encodedDataLength` is observed transferred response bytes for **this observation window**, not total app/package size; late/background resources and SW/cache-served resources can appear as zero. GDevelop slow/background promotional content differs from baseline, so its byte totals are not a matched transfer comparison. The Scratch tarball (149,932,350 bytes) and unpacked package (248,233,919 bytes) are not its browser payload; the one gzip-compressed 17,083,105-byte standalone JS is 5,700,431 bytes. JS heap and browser PSS include different things; neither certifies a low-RAM mobile target. The vendor's marketing/tracking hosts in the unauthenticated GDevelop run are a **privacy-review signal**, not proof of what personal data they collect.
