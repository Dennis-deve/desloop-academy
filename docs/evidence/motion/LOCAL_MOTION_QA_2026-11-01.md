Card glow tracks the pointer without React rerenders; CSS sheen/ripple is decorative. All text stays fully opaque during page-entry translation for contrast. No credentials, new storage, requests or client-owned course permissions are introduced.

**Failures found and fixed during this work:** (1) A global canvas+viewport hook initially failed in jsdom; the test environment now stubs unsupported 2D context and the production viewport code falls back when IntersectionObserver is absent. (2) Fading text during entry temporarily failed axe color contrast, so text remains opaque. (3) The reduced-motion ticker initially exposed an unfocusable scroll area; it now wraps and shows all nine labels without scrolling. (4) Touch emulation timed out clicking an orbiting button; on coarse/touch input the controls are stationary, with desktop hover/focus/pause retaining motion. (5) An `sr-only` helper not present in the standalone CSS was replaced by a self-contained visually-hidden helper. (6) Initial page focus cropped the top notice by about 18px; initial focus now prevents scrolling while subsequent route changes still move focus. Concurrent full-browser/unit runs once exhausted local CPU and hit 30-second timeouts plus a frontend flake; **sequential** full reruns passed. Final browser suites passed after these changes; this is not a claim that every possible accessibility mode is verified.
